GitHubChecking…
  1. Open GitHub → New fine-grained token.
  2. Name it BugSnap and choose the repositories under Repository access.
  3. Set Repository permissions → Issues to Read and write.
  4. For project boards of an organisation, pick it as Resource owner and set Organization permissions → Projects to Read and write. Boards on a personal account may need a classic token with the repo and project scopes.
  5. Generate it and paste it below.
