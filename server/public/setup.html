Your Google app

BugSnap uploads to your Drive through a Google app that you own. It can only see the files it creates. Open each link, do the step, come back.

  1. Create a project named BugSnap.
    Open
  2. Turn on the Google Drive API (check the BugSnap project is selected at the top).
    Open
  3. Set up the sign-in screen: Get started, app name BugSnap, your email, audience External, then Create.
    Open
  4. Add the Drive permission: Data Access, Add or remove scopes, paste this in "Manually add scopes", then Update and Save.https://www.googleapis.com/auth/drive.file
    Open
  5. Publish the app: Audience, Publish app, Confirm. Skip this and Google signs BugSnap out every 7 days.
    Open
  6. Create the sign-in client: Create client, type Desktop app, name BugSnap, Create. Copy the two values below.
    Open

Your share player

Share links open a small player page that streams from your Drive. You host it yourself, for free, wherever you like.

  1. Create an API key (Create credentials, API key). Then edit it: API restrictions, Restrict key, tick Google Drive API, Save. Paste it below.
    Open

Where should the player live?

  1. Import your copy on Vercel: sign in with GitHub (the free Hobby plan is enough), then Import your BugSnap copy. Not listed? Click Adjust GitHub App Permissions and give Vercel access to it. Leave the build settings as they are.
    Open
  2. Add the key, then Deploy: open Environment Variables, name DRIVE_API_KEY, value: your key. Click Deploy. It takes about a minute.DRIVE_API_KEY
  3. Copy the player address: on the project page, under Domains, the short one ending in .vercel.app. Paste it below.
  1. Give the key to your GitHub copy: New repository variable, name DRIVE_API_KEY, value: your key.DRIVE_API_KEY
    Open
  2. Turn on GitHub Pages: Source, GitHub Actions. Your copy must be public for this on a free account.
    Open
  3. Publish the player: Run workflow, Run workflow. It takes about a minute.
    Open
  1. Save your key below first (Save and check), then build the player: open a terminal in the server folder and run the command. It makes a viewer-site folder next to server.npm run build:viewer
  2. Upload the folder to any static host. The easiest: drag viewer-site onto Netlify Drop.

Add the browser extension

It records, takes screenshots and talks to this computer's BugSnap.

  1. Open the extensions page: chrome://extensions, brave://extensions or edge://extensions.
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and choose this folder:
  4. Pin BugSnap, click it, then the gear: add your name, an AI provider for bug reports, and the tools you report to (GitHub, Jira, GitLab, Slack, Notion).

You're set

Click the BugSnap icon on any website and record your first bug. Alt+Shift+S opens the capture bar.
